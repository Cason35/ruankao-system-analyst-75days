版本基线：2025 年考试采用的现行考试大纲 + 《系统分析师教程（第 2 版）》（ISBN 9787302669166）。课程已按新版教程 3 篇 22 章重新核对，详见 [`01-2025新版大纲对照.md`](./01-2025新版大纲对照.md)。历年题与第三方课程只用于校准考法，融合规则见 [`02-参考仓库融合方案.md`](./02-参考仓库融合方案.md)。在线章节练习作为额外题量，不替代原作业，逐日安排见 [`03-在线题库配套刷题表.md`](./03-在线题库配套刷题表.md)。

## 学习方式

每天按“授课 → 例题 → 方法总结 → 原作业 → 在线章节加练 → 批改 → 针对性复习”推进。

1. 当天课程保存在 `days/`。
2. 作业答题模板保存在 `homework/`。
3. 批改结果保存在 `reviews/`。
4. 在线题库使用[软考达人](https://ruankaodaren.com/exam/#/)对应章节，结果主动回填到作业或进度表。
5. `PROGRESS.md` 记录每日用时、作业得分、在线刷题结果、薄弱点和复习日期。
6. 下一课会根据上一份作业和在线错题结果动态调整。
