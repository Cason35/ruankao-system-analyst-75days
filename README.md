# 系统分析师 75 天学习档案

备考周期：2026-08-11 至 2026-10-24  
目标考试：2026 年下半年计算机技术与软件专业技术资格（水平）考试——系统分析师

## 学习方式

每天按“授课 → 例题 → 方法总结 → 作业 → 批改 → 针对性复习”推进。

1. 当天课程保存在 `days/`。
2. 作业答题模板保存在 `homework/`。
3. 批改结果保存在 `reviews/`。
4. `PROGRESS.md` 记录每日用时、得分、薄弱点和复习日期。
5. 下一课会根据上一份作业的结果动态调整。

## 目录

```text

```
